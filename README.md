# 진법 변환 연습기 / 进制转换练习器

## 1. 작품명 / 作品名称
**진법 변환 연습기 / 进制转换练习器**

## 2. 용도 / 用途
- **한국어**: 2진수, 8진수, 10진수, 16진수 간의 변환 결과를 즉시 확인하며 진법 개념을 익힐 수 있는 웹 기반 학습·연습 도구입니다.
- **简体中文**: 一款基于网页的进制学习与练习工具，可实时查看二进制、八进制、十进制和十六进制之间的转换结果。

## 3. 주요 기능 / 主要功能
- **한·중 병렬 UI / 韩中双语界面**: 제목, 진법 선택 옵션, 입력 안내, 버튼, 결과, 오류 메시지까지 모든 사용자 표시 문구를 한국어와 중국어 간체로 함께 제공합니다. / 标题、进制选项、输入说明、按钮、结果以及错误提示等所有用户可见文字均以韩语和简体中文并列显示。
- **4가지 진법 동시 변환 / 四种进制同时转换**: 2진수·8진수·10진수·16진수 중 하나를 선택해 0 이상의 정수를 입력하고 「변환 / 转换」 버튼을 누르면 네 가지 진법 결과를 동시에 표시합니다. / 选择二、八、十或十六进制中的任意一种并输入非负整数，点击「변환 / 转换」后同时展示四种进制的转换结果。
- **2진수 4자리 그룹 표시 / 二进制每4位分组显示**: 2진수 결과는 오른쪽에서 왼쪽으로 4자리씩 공백으로 구분하여 가독성을 높였습니다. (예: 10진수 `164` → 2진수 `1010 0100`, 8진수 `244`, 16진수 `A4`) / 二进制结果从右向左每四位用空格分组，方便阅读（例如：十进制 `164` → 二进制 `1010 0100`、八进制 `244`、十六进制 `A4`）。
- **큰 정수 지원 / 支持大整数**: JavaScript `BigInt`를 사용하여 자릿수가 큰 음이 아닌 정수도 정밀도 손실 없이 변환합니다. / 使用 JavaScript `BigInt`，超大非负整数也能精确转换。
- **구체적인 입력 오류 안내 / 具体的输入错误提示**: 빈 입력, 음수, 소수, 공백 포함, 선택한 진법에 맞지 않는 문자(예: 2진수에 `102` 입력) 등 오류 원인을 한국어와 중국어로 구체적으로 안내합니다. / 对空输入、负数、小数、含空格或不符合所选进制的字符（例如选择二进制却输入 `102`）提供具体明确的韩中双语错误提示。
- **결과 복사 및 예시 입력 / 复制结果与示例填入**: 각 진법 결과를 클릭 한 번으로 복사할 수 있으며, 예시 버튼으로 `10진수 164` 변환을 바로 테스트할 수 있습니다. / 支持一键复制各进制结果，并提供示例按钮可快速测试十进制 `164` 的转换。

## 4. 실행 방법 / 运行方法
- **한국어**: 별도의 서버나 설치 없이 순수 HTML, CSS, JavaScript로 제작되었습니다. 폴더 내의 `index.html` 파일을 더블 클릭하여 웹 브라우저로 열면 바로 사용할 수 있습니다.
- **简体中文**: 本项目仅使用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖或启动服务器。只需双击文件夹中的 `index.html`，使用任意现代浏览器打开即可直接运行。

## 5. 파일 구성 / 文件结构
- `index.html`: 메인 웹 페이지 구조 / 主页面结构
- `style.css`: 화면 레이아웃 및 스타일 / 页面布局与样式
- `script.js`: 입력 검증, 진법 변환 및 결과 표시 로직 / 输入校验、进制转换与结果展示逻辑
- `README.md`: 한국어·중국어 안내 문서 / 韩中双语说明文档
